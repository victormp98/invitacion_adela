# Invitación Fiesta Vaquera - Adela (51 Años)

Invitación digital interactiva para el cumpleaños 51 de Adela con temática vaquera.

## Ejecución Local

**Requisitos:** Node.js (v18+)

1. **Instalar dependencias:**
   ```bash
   npm install
   ```

2. **Iniciar la aplicación en modo desarrollo:**
   ```bash
   npm run dev
   ```

3. Abrir en el navegador: `http://localhost:3000`
